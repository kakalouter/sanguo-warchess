## 4. 关键发现与踩坑记录

1. **决定性线索来自仓库 README 的互相引用**：`renmu123/koei_san_data`（三国志11 数据）的 README 里写着「[人物头像](https://github.com/renmu123/koei_san_character_img)」——实际指向 `renmu123/koei_san_character_img`，一个 **570MB、5068 张** 光荣三国志人物头像全集，按游戏分目录（`san/39_s`、`310_s`、`311_s`、`312_s`、`313_s`），**文件名直接就是中文人名**（如 `san/311_s/曹操.jpg`）。这是本次成功的关键。
2. **选区策略**：只有 `311_s`(964) 与 `310_s`(872) 两套**同时满足**「有中文人名」+「单张 ≤100KB」；两套重名 786 人，合并去重后 **1052 个唯一名字**。
3. **`general.json` 上游文件本身是坏的**：该文件以 `" {\n  \"id\": 1..."` 开头（**缺少开头的 `[`**），却以 `]` 结尾，直接 `JSON.parse` 会报 `Unexpected non-whitespace character after JSON at position 346`。已用两个独立镜像（jsdelivr、ghproxy）交叉验证，确认是**上游文件问题，不是下载损坏**。修好开头方括号后解析正常：**670 条记录、666 个唯一姓名**。我保留了原始的 `general.json` 不动，另存了一份修好的 `general.repaired.json`。
4. **`power.json` 带 UTF-8 BOM**（文件头是不可见的 `U+FEFF`），直接 `JSON.parse` 会报 `Unexpected token` 且报错信息里那个字符显示为空白。需先 `replace(/^\uFEFF/, '')`。去掉 BOM 后是合法 JSON，**38 条记录**，结构为 `{powerId, general:{...}}`，`general` 内嵌完整武将对象。
5. **拼音文件名踩坑**：`pinyin-pro` 把「吕」拼成 `lü`，直接过滤非 `[a-z0-9]` 会把 `ü` 吃掉，得到 `吕布 → lbu.jpg`、`吕蒙 → lmeng.jpg`。已修正为 `ü → v`（`lvbu.jpg` / `lvmeng.jpg`）。另外把非中文字符直接丢弃会导致 `新武将_1` 与 `新武将_2` 撞名，已改为保留原串里的数字。
6. **同音重名按「人物知名度」重排**：诸葛亮/诸葛靓、张既/张济、张嶷/张翼 拼音完全相同。原始按字典序分配会把 `zhugeliang.jpg` 给诸葛靓。已改为用三国志11 数据里的**五维属性总和**作为知名度权重排序，现在 **诸葛亮 = `zhugeliang.jpg`、诸葛靓 = `zhugeliang-2.jpg`**，张既 = `zhangji.jpg`、张济 = `zhangji-2.jpg`。

## 5. 替代方案 / 后续建议

当前素材**数量足够（1052 张）、但许可证不干净**。如果本项目要对外发布，建议按以下优先级替换：

1. **自行绘制 / AI 生成**（最稳）：用现有 1052 张作为风格参考，生成原创头像，版权完全自主。
2. **CC0 素材站**：本机 `pixabay.com` API 可达（返回 400 说明连通，只是缺 API key），`openclipart.org` 也可达。可注册 key 后按 `three kingdoms / chinese warrior portrait` 检索 CC0 图。
3. **Wikimedia Commons 公共领域**：清宫《三国演义》绣像、历代君臣画像等属 PD，是**最理想的干净来源**。但本机 `commons.wikimedia.org`、`api.wikimedia.org`、`upload.wikimedia.org` 全被阻断，**在这台机器上拿不到**。若换一台网络不受限的机器，用 `commons.wikimedia.org/w/api.php?action=query&generator=categorymembers&gcmtitle=Category:Three_Kingdoms` 可批量拉取。
4. **购买授权**：光荣特库摩有官方素材授权渠道；或购买可商用的三国题材素材包（如 Unity Asset Store / 爱给网商用授权）。
5. **仅内部原型**：如果只是本地 three.js 原型验证，当前 1052 张可直接用，**不要提交到公开仓库**（建议把 `assets/portraits/` 加进 `.gitignore`）。
