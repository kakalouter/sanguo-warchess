# 三國志 · 漢末風雲

一个基于 **Three.js** 的 3D 三国志风格回合制战棋游戏。单机、离线可玩，双击 `index.html` 即可开局。

- **剧本**：189 年 · 反董卓联盟（群雄并起），**17 家势力可选**
- **地图**：真实中国高程数据（DEM）渲染的 3D 地形，含长江、黄河、淮河、珠江、辽河等真实水系，**89 座城池与关隘**
- **武将**：**670 名**（205 名归入势力 + 130 名在野），属性/兵种适性/列传取自《三国志11》原始数据；头像 **1052 张**（覆盖 838 人）
- **战斗**：三国志11 风格战棋 —— 6 兵种相克、9 种地形加成、**36 位武将专属战法**、士气与训练、天候变化
- **规模**：手写代码约 6000 行，无构建步骤、无 CDN 依赖

## 一、如何运行

### 方式一：双击打开（推荐）
直接双击 `index.html`。所有资源都是本地相对路径，无需服务器。

> 少数浏览器对 `file://` 下的本地图片有额外限制。若发现武将头像不显示，改用方式二。

### 方式二：本地服务器
在本目录下任选一种：

```bash
python -m http.server 8000
# 或
npx serve .
```

然后浏览 `http://localhost:8000/`。

浏览器需支持 WebGL2（Chrome / Edge / Firefox 现代版本均可）。

## 三、玩法

### 1. 内政（每月每名武将可行动一次）
| 指令 | 消耗 | 效果 |
|---|---|---|
| 开垦 | 金 320 | 提升**农业** → 影响 3 月/9 月秋收粮产 |
| 兴商 | 金 320 | 提升**商业** → 影响每月金收入 |
| 技术 | 金 420 | 提升**技术** → 同时提高收入与产量 |
| 修城 | 金 260 | 提升**城防** → 提高守城战力 |
| 治安 | 金 180 | 降低**民怨**、提升**治安**与民心 |
| 征兵 | 每兵 0.11 金 + 0.35 粮 | 消耗人口换兵力，会抬高民怨、压低民心 |
| 训练 | 金 220 | 提升**训练度** → 直接提高部队攻防 |
| 登用 | 金 400 | 说服本城在野武将归顺（成算取决于说服者魅力/智力） |

民心与治安低下会显著削减收入与产量，并增加逃兵——所以要平衡征兵与发展。

### 2. 军事与后勤
- **出兵**：从己方城池选择最多 3 名武将（首位为主将），携带兵力出征。出征时自动携带 **6 倍兵力**的粮草。
- **行军**：部队按城池邻接图推进，每回合有移动力上限；途经己方城池会自动补给粮草。
- **断粮**：粮草耗尽则士卒大量逃散，兵力低于 300 时整支军团溃散。
- **运输**：可向**相邻**己方城池调拨粮草（途中损耗 8%）。
- **驻守耗粮**：城内驻军每月也消耗粮草，粮尽则逃兵、民心下降。
- **任命**：在本势力城池之间调动武将。

### 3. 战斗（战棋）
- 战场由**当地真实 DEM 高程**切片生成：山地、丘陵、森林、平原、水面、城郭、道路，不同地形有不同移动消耗与防御加成。
- **兵种相克**：枪克骑、戟克枪、弩克枪、骑克弩。武将的兵种适性（S/A/B/C）决定其在该兵种上的发挥，出兵时自动选取适性最高的兵种。
- **战法**：每名武将独有。例如吕布「无双」、关羽「青龙偃月」、张飞「长坂怒吼」（范围）、赵云「七进七出」（不被反击）、诸葛亮「八阵图」、周瑜「火烧赤壁」。高武力/高智力决定威力，部分战法为范围伤害或无视反击。
- **士气**：受战法与劣势影响，士气归零或兵力低于 12% 时部队可能溃散。
- **天候**：晴 / 雨 / 大风 / 雾 / 雪，影响命中率、火计威力与行军速度。
- **胜负**：攻方全歼守军即夺城；守方全歼攻军即守住。破城后可俘获或招降敌将。

### 4. 胜负条件
消灭所有敌对势力即**天下一统**；失去全部城池则**大势已去**。

### 5. 存档
- 顶栏「存档」→ **导出为文件**：下载 `.sgsav.json` 到本地，可随时导入。
- 另有 4 个浏览器存档槽（localStorage）。

## 六、重新生成数据（可选）

`js/mapdata.js`、`js/data_generals.js`、`js/data_portraits.js` 都已生成好，**正常运行无需重建**。若想改动：

```bash
node _source/bake.js        # 地形：改地图范围/精度/配色后运行
node _source/roster.js      # 武将名册：改势力归属或成员后运行
node _source/manifest.js    # 头像索引：素材变动后运行
```

`_source/` 缺少什么会自行提示。`bake.js` 需要 `_source/ne/`（Natural Earth 原始数据）与 DEM 瓦片缓存 `_source/dem_cache/`——缓存丢了它会自动重新下载 99 张瓦片（需联网）：

```bash
node _source/fetch-tiles.js   # 可选：预下载 z6 瓦片
```

`bake.js` 会：
- 从 AWS 拉取 z6 瓦片（覆盖 73.1°E–135.0°E / 16.6°N–55.8°N），带重试与本地缓存
- 栅格化 Natural Earth 河流/湖泊，沿河道下切形成河谷
- 按海拔分段着色 + 西北向山体晕渲，输出绢本地图质感贴图
- 高程做 `h^0.78` 非线性压缩（低地保细节、高山不夺目），并轻度高斯平滑
- 输出 `gridPNG`（560×400 战略网格）、`batPNG`（1024×832 战场切片）、`texPNG`（1120×800 贴图）

细节与调参入口见 [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md#4-地形烘焙管线)。
